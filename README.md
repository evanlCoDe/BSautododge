# Screen Tracker V2 scaffold
Project Overview

This project is an educational computer vision prototype developed to explore real-time object detection, motion tracking, and prediction algorithms. The primary purpose of the project is to gain practical experience in software development, artificial intelligence concepts, and computer vision techniques in a controlled testing environment.

The application is written in Python and developed using Visual Studio Code (VS Code). It uses the OpenCV library for image processing and computer vision tasks. Video frames are analyzed to detect motion, track moving objects, and make short-term predictions about object movement based on observed trajectories.

The project follows a modular code structure, with separate components responsible for image processing, region-of-interest detection, object tracking, prediction, and debugging. This organization improves readability, maintainability, and future development.

Artificial intelligence concepts are incorporated through prediction algorithms that estimate the future positions of detected objects. These predictions are intended for experimentation and learning rather than perfect accuracy, allowing different tracking methods and parameters to be evaluated.

Development and testing are conducted in a controlled environment using recorded gameplay and experimental scenarios to evaluate the performance of the detection and prediction systems. Testing focuses on improving accuracy, reducing false detections, and measuring algorithm performance under different conditions.

This project draws inspiration from real-world computer vision applications, including technologies used in autonomous systems such as Tesla’s driver-assistance and autonomous driving systems, where cameras, computer vision, and predictive algorithms are used to identify and anticipate the movement of surrounding objects. While this project operates on a much smaller scale and serves a different purpose, it applies similar foundational computer vision concepts for educational learning.
