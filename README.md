# Screen Tracker V2 scaffold
This module is responsible for detecting regions of movement between consecutive video frames. It first converts each frame to grayscale to reduce computational complexity. The current frame is then compared with the previous frame using frame differencing to identify changes in pixel values. A binary threshold is applied to isolate significant motion while reducing minor image noise. Contours are extracted from the resulting binary image, and bounding rectangles are generated around each detected moving region. Small detections below a specified area threshold are discarded to reduce false positives. The final output is a list of bounding boxes representing areas of motion, which are used as Regions of Interest (ROIs) for subsequent tracking and analysis.
